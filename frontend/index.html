    Import Stock

    Upload an Excel (.xlsx), CSV or tab/semicolon-separated text file. The first row must be column names. Recognised columns: name, price, quantity, illness, type, form, pharma, country, ingredients, dosage, schedule, expiry_date, rx. Ingredients can be separated with ;. Existing medicines are updated, new ones are added.
